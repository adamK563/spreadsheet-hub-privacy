# Privacy Policy for Spreadsheet Hub

**Data we access**  
• We only read your Google Drive file metadata (sheet names, IDs, last‐edited timestamps, owner and last-editor display names) via the Drive API.  
• We use OAuth (`identity` permission) to authenticate you.  

**Data we store**  
• We store only your pinned‐sheet IDs in `chrome.storage.local`—never on our servers.  

**Data we never collect**  
• We do not collect, store, or transmit your actual sheet contents, email address, browsing history, location, or any other personal data beyond the metadata above.  

**Sharing**  
• We do not sell or share any data with third parties.
